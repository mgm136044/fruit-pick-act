# 후속 지시 (학교학습1 세션): 학습이 끝나면 zip·형식 검사·업로드가 저절로 되게 하기

> 이 세션: mix2 chunk 50 10만(앞 지시 `20261126_학교학습1_mix2_chunk50_지금시작.md`) · 폴더 `/home/work/act_mix2_c50` · 학습 이름 `act_mix2_c50` · 올릴 곳 `mgm136044/act_mix2_c50`(비공개)

## 왜
- 앞 지시의 'zip 만들기·업로드' 단계는 에이전트가 학습이 끝날 때까지 깨어 있어야 한다. 학습이 끝났을 때 에이전트가 쉬고 있으면 아무것도 올라가지 않는다.
- 그래서 **학습 끝을 스스로 기다렸다가 그 단계를 대신 하는 스크립트**를 nohup 으로 띄운다. 하는 일은 앞 지시와 같다.
  - zip 4개를 만든다. te 는 사본 config.json 의 두 값만 바꾼다.
  - 서버 실행 방식으로 형식 검사(act 240번)를 하고 sha256 을 잰다.
  - 비공개 저장소에 올린다. README 는 이미 있으면 받아서 이 학습의 절을 덧붙인다.
  - 업로드 뒤 서버의 크기·sha256 을 대조한다.
- **이제 그 단계는 이 스크립트가 한다. 에이전트는 직접 하지 않는다.** 직접 하는 것은 스크립트가 ✘ 로 끝났을 때뿐이다(같은 파일을 두 번 올리지 않기 위해).

## 2. 스크립트 받기 (비공개 데이터셋 저장소)
```bash
cd /home/work/act_mix2_c50
huggingface-cli download mgm136044/fruit_mix3_train tools/auto_finish_upload.py --repo-type dataset --local-dir .
cp tools/auto_finish_upload.py ./auto_finish_upload.py
sha256sum auto_finish_upload.py   # 08fe1f748235d5faeb36b18464a5dff941ed5ffb755c999478effc7d740dd33e
```
- sha256 이 다르면 실행하지 말고 보고한다.

## 3. 띄우기
- 학습에 쓴 python 으로 띄운다. `train.log` 의 '학습 시작 · <python 경로>' 줄에 있다.
- HF 로그인이 되는 셸에서 띄운다(토큰을 넣은 셸). nohup 으로 띄우면 그 셸의 환경을 물려받는다.
```bash
cd /home/work/act_mix2_c50
PY=$(grep -o '학습 시작 · .*' train.log | tail -1 | sed 's/^학습 시작 · //'); echo "$PY"; "$PY" -c "import lerobot, huggingface_hub; print('ok')"
nohup "$PY" auto_finish_upload.py --name act_mix2_c50 --repo mgm136044/act_mix2_c50 \
  --zips 100000:plain:submission_act_mix2_c50_100k,100000:te:submission_act_mix2_c50_100k_te,80000:te:submission_act_mix2_c50_80k_te,60000:te:submission_act_mix2_c50_60k_te \
  --note "fruit_scripted_mix2 (589ep, 스크립트 자동 시연, 사람 시연 아님) · chunk 50 · 색 증강 4종" > auto_finish_act_mix2_c50.log 2>&1 &
sleep 30; cat auto_finish_act_mix2_c50.log
```

**띄운 직후 로그에서 확인할 것**
- `HF 확인: 사용자 mgm136044, mgm136044/act_mix2_c50 …(비공개)`
- 학습 중이면 `학습 프로세스 감지: [pid …]`. 이미 끝났으면 `없음 · 최종 저장 지점 있음` 이 나오고, 1분 뒤 zip 만들기가 시작된다.

**이런 줄이 나오면**
- `✘ HF 로그인 안 됨` → 사람에게 토큰을 요청한다. 사람이 `export HF_TOKEN=...` 이나 `huggingface-cli login` 을 한 **같은 셸에서** 다시 띄운다. 토큰을 파일·로그에 쓰지 않는다.
- 학습 중인데 `학습 프로세스 감지: 없음` 이면, 스크립트가 5분 뒤 `✘ … 학습이 멈춘 것 같다`(종료 코드 3)로 끝난다 → `ps aux | grep lerobot_train` 결과와 함께 보고한다.

## 4. 끝 확인
- 학습이 끝나고 몇 분 뒤 로그 마지막 줄이 `AUTO_UPLOAD_DONE` 이면 성공이다. 바로 위 줄이 `업로드 확인: … 크기·sha256 일치` 다.
- 에이전트가 그때 깨어 있으면 로그의 zip 이름·sha256·검사 결과를 보고한다. 깨어 있지 않아도 업로드는 된다.
- `✘` 로 끝나면 그 줄을 보고하고, 앞 지시의 해당 단계를 직접 한다.
